The backend reads its settings from environment variables. When it starts it also loads a `.env` file from its
working directory, so `backend/.env` works. Secrets and machine-specific values belong in `.env`. The non-secret
defaults live in `backend/src/quantum_backend_v2/config/constants.py`, and each one can still be overridden by the
environment variable of the same purpose, which is the one named below. The sample `backend/.env.example` sets only
`QB2_AUTH_REQUIRED=false` and `QB2_LIBP2P_DEV_SERVICE_PEER_COUNT=4` away from the code defaults.

## Service

| Variable | Default | Purpose |
| --- | --- | --- |
| `QB2_ENVIRONMENT` | `development` | Label shown in health output. |
| `QB2_SERVICE_NAME` | `quantum-backend` | Service name in logs and health output. |
| `QB2_API_HOST` | `0.0.0.0` | Bind address. |
| `QB2_API_PORT` | `8081` | Bind port. |
| `QB2_LOG_LEVEL` | `INFO` | Standard Python log level. |
| `QB2_JSON_LOGS` | `true` | Structured JSON logs. Set `false` for simpler local logs. |

## Authentication

| Variable | Default | Purpose |
| --- | --- | --- |
| `QB2_AUTH_REQUIRED` | `true` | When `false`, every request is treated as a local administrator. `.env.example` sets `false`. **Never disable this in production.** |
| `QB2_ALLOW_DEV_BEARER_TOKENS` | `false` | Accept `Bearer dev-<user_id>` tokens even when authentication is required. For controlled local testing only. |

## MongoDB

| Variable | Default | Purpose |
| --- | --- | --- |
| `QB2_MONGODB_URI` | none, **required** | The one MongoDB connection string every backend service uses: `mongodb://127.0.0.1:27017` locally, or an Atlas `mongodb+srv://` URI. The backend stops at startup with `MongoDB is not configured. Set QB2_MONGODB_URI.` if it is missing. |
| `QB2_MONGODB_DATABASE` | `qds` | Database name. |
| `QB2_MONGODB_SERVER_SELECTION_TIMEOUT_MS` | `5000` | How long to wait for a server. |

## Peer log

| Variable | Default | Purpose |
| --- | --- | --- |
| `QB2_PEER_ID` | `qb2-local-peer` | Identity written into the peer log. |
| `QB2_PEER_LOG_DIR` | `./quantum-backend/peer-logs` | Where the append-only log is written, relative to the folder the backend starts in. |
| `QB2_PEER_LOG_FSYNC` | `true` | Flush every write to disk. |

## libp2p

| Variable | Default | Purpose |
| --- | --- | --- |
| `QB2_LIBP2P_ENABLED` | `true` | Run the libp2p host. |
| `QB2_LIBP2P_PEER_ID` | `qb2-local-peer` | The coordinator's peer label. Its peer ID is derived from this, so it stays the same across restarts. Embedded helper peers are named `<label>-worker-<n>`. |
| `QB2_LIBP2P_LISTEN_MULTIADDRS` | `/ip4/0.0.0.0/tcp/4011` | Comma-separated listen addresses. |
| `QB2_LIBP2P_ADVERTISE_MULTIADDRS` | empty | Addresses to advertise, if different. |
| `QB2_LIBP2P_BOOTSTRAP_PEERS` | empty | Comma-separated peers to dial on startup. Empty for a coordinator. Embedded helper peers are pointed at the coordinator automatically. A backend that has bootstrap peers also re-dials any that drop, every 15 seconds. |
| `QB2_LIBP2P_RENDEZVOUS_NAMESPACE` | `quantum-backend` | Prefix for the discovery topics and protocol ids. |
| `QB2_LIBP2P_PEERSTORE_PATH` | `./quantum-backend/libp2p/peerstore.sqlite3` | SQLite peerstore file. |
| `QB2_LIBP2P_ACTIVATE_LISTENERS` | `true` | Start the listeners. |
| `QB2_LIBP2P_HEARTBEAT_INTERVAL_SECONDS` | `5` | Heartbeat period (minimum 5). A peer also re-sends its service advertisement every fifth heartbeat. A remote worker uses its own `--heartbeat` flag, default 10. |
| `QB2_LIBP2P_STALE_PEER_TTL_SECONDS` | `300` | Time without a message before a peer is stale (minimum 30). |
| `QB2_LIBP2P_DEV_SERVICE_PEER_COUNT` | `0` | Embedded worker peers to start in this process (0 to 32). `.env.example` sets `4`. It is deliberately not a code constant, so a production deployment never starts dev workers by accident. For workers on other laptops, see [Run a mesh](/docs/mesh/overview). |
| `QB2_LIBP2P_DEV_SERVICE_BASE_PORT` | `4021` | First port used by embedded workers. |

## Credits and payments

| Variable | Default | Purpose |
| --- | --- | --- |
| `QB2_CIRCUIT_JOB_CREDIT_COST` | `0` | Credits held per circuit job. `0` turns metering off. |
| `QB2_X402_GATEWAY_SECRET` | none | Enables the hidden internal routes used by the [x402 gateway](/docs/integrations/x402). Must equal the console's `X402_GATEWAY_SECRET`. |
| `QB2_BILLING_INTERNAL_SECRET` | none | Shared secret for the console's billing calls. |
| `QB2_PAYMENT_RECONCILE_INTERVAL_SECONDS` | `300` | How often the payment reconciliation sweep runs. |
| `QB2_WORKER_PAYOUT_WALLET` | none | The platform wallet that sends [worker payouts](/docs/integrations/credits-ledger#paying-workers). Unset means payouts accrue and nothing is sent. |
| `QB2_WORKER_PAYOUT_THRESHOLD` | `1` | Send once a worker's accrued USDC reaches this. |
| `QB2_WORKER_PAYOUT_MAX_AGE_SECONDS` | `86400` | Or once their oldest unpaid fragment is this old. |
| `QB2_WORKER_PAYOUT_INTERVAL_SECONDS` | `300` | How often the settler runs. `0` turns sending off. |
| `QB2_WORKER_PAYOUT_MIN_FIDELITY` | `0` | Fragments below this observed fidelity (0 to 1) are not paid. |

## Content node and provenance

| Variable | Default | Purpose |
| --- | --- | --- |
| `KUBO_RPC_URL` | `http://kubo:5001` | The private RPC address of the Kubo node. |
| `KUBO_RPC_SECRET` | none | Private token shared with Kubo. Setting it turns on [bundle publishing](/docs/concepts/provenance). |
| `KUBO_RPC_TIMEOUT_SECONDS` | `30` | Maximum 300. |
| `KUBO_RPC_MAX_RESPONSE_BYTES` | `4194304` | Maximum 64 MiB. |
| `IPFS_GATEWAY_URL` | `http://kubo:8080` | Private gateway used to read content. |
| `IPFS_PUBLIC_GATEWAY_URL` | none | Browser-facing gateway origin, used to build "open evidence" links. |
| `IPFS_GATEWAY_TIMEOUT_SECONDS` | `30` | |
| `IPFS_GATEWAY_MAX_RESPONSE_BYTES` | `4194304` | |
| `QB2_ANCHOR_NETWORK` | none | Turns on anchor verification. A registry alias or CAIP-2 id of a test network with the `anchor_root` capability. |
| `QB2_ANCHOR_SENDER` | none | Public address of the anchor account. |
| `QB2_ANCHOR_PAST_SENDERS` | empty | Comma-separated earlier anchor accounts, kept so old anchors still verify. |
| `QB2_ANCHOR_PRIVATE_KEY` | none | A dedicated low-balance key. With it, the backend also sends anchors on a schedule. |
| `QB2_ANCHOR_INTERVAL_SECONDS` | `3600` | Scheduled anchoring period. |
| `QB2_ANCHOR_MAX_BATCH` | `10000` | Most bundles per batch. |

<Callout>
  Treat every variable above that holds a secret (`QB2_X402_GATEWAY_SECRET`, `QB2_BILLING_INTERNAL_SECRET`,
  `KUBO_RPC_SECRET`, `QB2_ANCHOR_PRIVATE_KEY`, `WALLET_ENCRYPTION_KEY`, `STARKNET_RELAYER_PRIVATE_KEY`, every API key) as private. Never expose one to a browser, and never commit a
  `.env` file.
</Callout>

## Remote worker script

`scripts/run_remote_worker.py` takes flags, not environment variables, and needs no `.env` file. See
[Start a worker](/docs/mesh/workers#worker-options).

| Flag | Default | Purpose |
| --- | --- | --- |
| `--coordinator` | required | `/ip4/<host>/tcp/<port>/p2p/<peer-id>` or `/dns4/...`. |
| `--label` | required | Unique name, 3 to 64 characters of letters, digits, `.`, `_` and `-`. It derives the peer ID. |
| `--namespace` | `quantum-backend` | Must match the coordinator's `QB2_LIBP2P_RENDEZVOUS_NAMESPACE`. |
| `--heartbeat` | `10` | Seconds between heartbeats. |
