QMesh connects to payment rails, blockchains, storage networks and AI providers. This page lists them all and says
honestly where each one stands. It was written from the pull requests and issues of
[QMeshPy/distributed-quantum](https://github.com/QMeshPy/distributed-quantum) as they stood on **1 November 2026**.
Those change daily, so check the linked pull request for the current state.

<Callout type="warn" title="Testnets and simulators">
  Every chain and payment integration below targets a **test network** or Stripe **test mode**, and quantum
  execution is simulated. The project's own ground rules say so: testnet first, and no feature is described as
  running on quantum hardware. See [Scope](/docs/scope).
</Callout>

## The three states

| State | Meaning |
| --- | --- |
| **In main** | The pull request is merged. The code is in the default branch. It may still be switched off by default. |
| **In review** | A pull request is open and not merged. Details can change. |
| **Proposed** | Only an issue exists. It is a plan, not a feature. |
